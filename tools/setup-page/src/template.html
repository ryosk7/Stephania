Stephania setup QR

This page creates, inside this browser, the secret used to register the owner of a Stephania device. It makes no network connections (the page CSP forbids them) and works offline.

This browser does not provide secure random numbers and hashing here. Open the page again over HTTPS or as a file:// URL.

  1. Download stephania-setup.txt
  2. Copy the downloaded file to the top level of the boot (FAT32) partition of the microSD card with the OS.
  3. Insert the microSD card into the Stephania device and power it on. The first boot imports the file and deletes it from the card.
  4. Scan this QR code with the Stephania Connect app to register as the owner over BLE.
  5. When registration is done, and close this tab.

This QR code and the file are the ownership of the Stephania device. Do not show them to anyone or put them in shared folders or chats, and do not hand the microSD card to anyone before registration. A Stephania device that already has an owner ignores and deletes the file without changing its secret.

Page integrity: compare this file's SHA-256 with SHA256SUMS published alongside it.
