# Public generic QEMU image
GHCR package ghcr.io/ryosk7/t3box-qemu-lab contains only Ubuntu kernel, selected device modules, minimal userspace and package metadata. The build context is an explicit two-file allowlist. T3Box source, binaries, stream credentials and test data never enter the published image. The private probe is overlaid locally at boot. Package visibility is managed separately in GitHub package settings; new GHCR packages default private. Public distribution requires reviewing applicable upstream redistribution/source obligations. Image tags derive from build recipe hash; consumer uses immutable digest and Actions cache. Rebuilding after Ubuntu security updates requires changing recipe/version. The 60-second gate excludes cold image preparation, package installation, cache restoration and Rust compilation; no claim of total workflow runtime or Pi 5 performance. Kernel capture probe only; ARM64 native full-stream integration remains separate.
