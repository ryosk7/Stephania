# Virtual Lab bootstrap

Independent experiment on PR45. Three jobs: kernel capability probe, production controller with existing virtual input, controller with vivid and ALSA loopback. Kernel modules unavailable is a failed prerequisite, not a pass or physical-device claim. The controller uses ci-virtual solely for local CA and synthetic input (unset in kernel mode). All four optional native controls enabled. No FFmpeg publisher; FFmpeg is audio stimulus and decoder only. The receiver is a minimal protocol peer, not YouTube. Tests 1080p30 HTTP lifecycle, decoded A/V, receiver FPS and estimated missing frames. No true capture latency or lip sync measurement yet. No old CI changes. Next: kernel capability remediation, stable device selection, deterministic mixed media and fault scenarios, physical calibration.
