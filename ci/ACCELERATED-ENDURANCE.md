# Accelerated three-hour endurance
Normal ARM64 logical CI has a 60-second execution budget, excluding build. It runs the existing full-duration clock drift and bounded queue/reconnect tests, PCM equivalence test, and two new exhaustive event-count tests: 324000 video + 506250 audio RTMP messages serialized and read back using the production implementation (synthetic payloads); 10800 TCP observations across 60 congestion and recovery cycles using the production AIMD policy. No sleeps, no full-resolution pixel work. Full three-hour real-time codec and controller soaks remain opt-in for thermal, native codec memory, device and real network behavior. These are not claimed to be equivalent. CI requires explicit success of all five accelerated tests.
