# Generic CI images (GHCR)
Public-compatible packages: stephania-ci-build (amd64/arm64), stephania-ci-runtime (arm64), stephania-ci-media-tools (arm64), stephania-ci-qemu-tools (arm64), and the separate stephania-qemu-lab boot image. Only Dockerfile is passed into each build context; no checkout, binaries, secrets or licensed external media are copied. Recipe hashes name the tags, but a tag can be overwritten by any workflow with packages: write, so the content behind it is not pinned; pull.sh reports the digest it got. Release builds never pull: they build the recipe in the run (STEPHANIA_CI_IMAGE_LOCAL=1, ci/README.md "Workflow security"). Review upstream redistribution obligations before changing package visibility. GHCR package visibility defaults private and must be changed by owner; workflow cannot do so with current connector. Runtime benchmark uses the public-compatible base plus a private local layer; never push that derived layer. Build action is available for migration after image validation. Media tools and QEMU tools are published first; native host workloads involving netem, module loading, Docker resource quotas and performance remain on host until equivalent execution validated. Source-specific Rust cache and external media are private. First push and cold pull are not 60-second guarantees.
