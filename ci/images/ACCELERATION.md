# CI acceleration
Build native binaries once per ARM64 workflow, distribute same-run artifacts (not public GHCR). Native test jobs remain isolated on native hosts, preserving network and CPU constraints. Generated mixed fixture cache is content checked; external media is not cached publicly. QEMU publisher is separate; cached boot image is restored directly without a serial publisher job. Artifact compression disabled for binary and video-heavy output. Main CI gate explicitly requires shared build success. No quality thresholds changed. Cold image availability, private package auth, ABI and total runtime still need validation.
