Ready in four steps.

No monitor, keyboard or terminal. The phone app does the rest.

  1. 1

    Download

    Get stephania-os-pi5.zip from the latest release.

  2. 2

    Copy to microSD

    Extract the ZIP onto a FAT32 microSD card. That's it — no flashing tool.

  3. 3

    Power on

    Insert the card and power the Pi 5. It verifies the signed system and installs itself.

  4. 4

    Tap Set up

    Open Stephania Connect nearby. The first phone to set it up owns it. Plug in a LAN cable, or pick its Wi-Fi.

Made for meetups, not studios.

Your phone is the camera

Stephania Connect sends both cameras over WebRTC and switches layouts with one tap.

Studio in the browser

Arrange slides, cameras, images and text in Stephania Studio from any browser on the LAN.

Private by design

No account, no cloud relay. The owner key stays on your phone; the LAN uses a pinned TLS certificate.

Updates that roll back

Signed RAUC bundles install to the other slot; a failed boot returns to the last good system.

Wired or Wi-Fi

With a LAN cable it's ready at once. Otherwise choose a network from the list the box can see.

Open, end to end

Rust engine, Ruby control plane, React Studio and an Expo app, all MIT on GitHub.

In development

The engine, apps, OS image and installer are built and tested in CI on QEMU and ARM64. Qualification on physical Raspberry Pi 5 hardware — HDMI capture, thermals, power and multi-hour runs — is still open. Stephania Connect is not in the app stores yet; build it from apps/mobile.
