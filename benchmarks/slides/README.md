# Independent technical slide benchmark

Branch-only push trigger is used because the connector cannot dispatch workflows. Existing CI is unchanged. Seven approved decks, four native encoder profiles, four evenly spaced pages held for 45 frames each. OCR compares reference OCR to decoded OCR, not ground truth. Images and PDFs are temporary; only numerical evidence is uploaded to avoid redistributing copyrighted slides. ARM64 hosted runners are not Pi 5 hardware.
